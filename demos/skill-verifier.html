Install

Drag the button to your bookmarks bar, then click it on a logged-in Service Operations Workspace page (/now/sow/). A full-screen panel runs every skill claim against your live instance. Press Ctrl+Shift+B if the bookmarks bar is hidden.

Skill Verifier drag to your bookmarks bar
Read-only guarantee. Uses GET only. Never PATCH/POST tickets, never order_now, never mutates tabConfig/mainConfig. Stops the suite early on HTTP 429 to protect your Table API budget. Soft/instance-specific claims warn instead of fail.
  1. auth

    g_ck / NOW / meta X-UserToken, credentials:include, user_sys_id shape.
  2. api
    Table / Stats / Presence / query ops

  3. domain
    Caller fields, journals, prefixes, relations
    Per-table caller fields, silent journal ACL, INC/RITM/REQ/… prefixes, RITM↔REQ links.
  4. dom
    SPA, shadow DOM, selectors, AMB
    /now/sow/ URLs, chrome tabs, contact cards, g_ambClient (not window.amb), Genesys softphone.
  5. report
    Pass / fail / warn / skip + JSON export
    Re-run failures, copy a full JSON report for skill audit diffs.
